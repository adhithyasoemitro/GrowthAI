# GrowthAI Admin Panel - Jatis Mobile

Sales Dashboard untuk mengelola leads dan tracking demo engagement.

## Tech Stack
- Next.js 14
- React 18
- TypeScript
- Tailwind CSS

## Setup

```bash
cd admin-panel
npm install
npm run dev
```

## Deployment

```bash
vercel deploy
```

## Branding

Project ini adalah bagian dari **GrowthAI** oleh **Jatis Mobile**.
